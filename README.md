# Filmtipp

Ein Klingelknopf, der je nach Stimmung einen guten Spielfilm oder eine gute Serie vorschlägt, die gerade bei ARD, ZDF, arte, Netflix oder Prime Video läuft.

App: https://wurstgott.github.io/filmtipp/

- `index.html` – die App
- `films.json`, `series.json` – das Programm, wird jeden Morgen automatisch neu recherchiert
